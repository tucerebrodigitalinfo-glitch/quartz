24 buenos recursos para aprender arquitectura de software en 2025

los recursos pueden dividirse en diferentes tipos, como:

Libros de diseño de software
Algunos libros que pueden ayudar son DDIA, System Design Volume 1 & 2, Clean Architecture, Domain-Driven Design y Software Architecture: the Hard Parts.

Blogs y boletines técnicos
Lee blogs técnicos de empresas como Netflix, Uber, Meta y Airbnb. Además, el boletín ByteByteGo ofrece cada semana información sobre el diseño de software.

Canales de YouTube y recursos de arquitectura
Canales de YouTube como MIT Distributed Systems, Goto Conferences y ByteByteGo pueden ayudar con la arquitectura de software y el diseño de sistemas. Azure Architecture Center y AWS Architecture Blog son otros recursos importantes.

Libros blancos
Para obtener información más detallada, lea libros blancos como Facebook Memcache Scaling, Cassandra, Amazon DynamoDB, Kafka y Google File System.

Software Career Books
Un Arquitecto de Software también necesita desarrollar habilidades holísticas. Libros sobre aspectos de la carrera de software como Pragmatic Programmer, The Software Architect Elevator, The Software Engineer's Guidebook, y Philosophy of Software Design pueden ayudar.
