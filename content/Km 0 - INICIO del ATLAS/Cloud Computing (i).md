## LIBROS

- "Cloud Computing: Concepts, Technology & Architecture — Thomas Erl, Ricardo Puttini y Zaigham Mahmood" (https://www.pearson.com/en-us/subject-catalog/p/cloud-computing-concepts-technology--architecture/P200000009505) — Introducción estructurada a modelos, mecanismos, arquitectura y patrones cloud.

- "Architecting the Cloud — Michael J. Kavis" (https://www.wiley.com/en-us/Architecting+the+Cloud%3A+Design+Decisions+for+Cloud+Computing+Service+Models+%28SaaS%2C+PaaS%2C+and+IaaS%29-p-9781118617618) — Decisiones de diseño para modelos SaaS, PaaS e IaaS.

- "Designing Distributed Systems — Brendan Burns" (https://www.oreilly.com/library/view/designing-distributed-systems/9781491983638/) — Patrones y componentes reutilizables para sistemas distribuidos y contenedores.

- "Kubernetes: Up and Running — Brendan Burns, Joe Beda, Kelsey Hightower y Lachlan Evenson" (https://www.oreilly.com/library/view/kubernetes-up-and/9781098110192/) — Guía práctica para desplegar y operar aplicaciones en Kubernetes.

- "Cloud Native DevOps with Kubernetes — John Arundel y Justin Domingus" (https://www.oreilly.com/library/view/cloud-native-devops/9781098116811/) — Prácticas de DevOps y operación de aplicaciones cloud native.

- "Infrastructure as Code — Kief Morris" (https://www.oreilly.com/library/view/infrastructure-as-code/9781098114664/) — Principios para automatizar y administrar infraestructura mediante software.

- "Terraform: Up & Running — Yevgeniy Brikman" (https://www.oreilly.com/library/view/terraform-up-and/9781098116736/) — Guía para aprovisionar infraestructura reproducible en múltiples proveedores.

- "Site Reliability Engineering — Betsy Beyer, Chris Jones, Jennifer Petoff y Niall Richard Murphy" (https://sre.google/books/) — Principios de fiabilidad, automatización y operación de servicios a gran escala.

- "The Site Reliability Workbook — Betsy Beyer, Niall Richard Murphy, David K. Rensin, Kent Kawahara y Stephen Thorne" (https://sre.google/workbook/table-of-contents/) — Aplicación práctica de métodos de ingeniería de fiabilidad.

- "Building Microservices — Sam Newman" (https://www.oreilly.com/library/view/building-microservices-2nd/9781492034018/) — Diseño, despliegue y evolución de arquitecturas basadas en microservicios.

- "Monolith to Microservices — Sam Newman" (https://www.oreilly.com/library/view/monolith-to-microservices/9781492047834/) — Estrategias para migrar sistemas tradicionales hacia arquitecturas distribuidas.

- "Release It! — Michael T. Nygard" (https://pragprog.com/titles/mnee2/release-it-second-edition/) — Patrones para construir sistemas de producción estables y resilientes.

- "Designing Data-Intensive Applications — Martin Kleppmann" (https://www.oreilly.com/library/view/designing-data-intensive-applications/9781491903063/) — Fundamentos de almacenamiento, procesamiento y arquitectura de datos distribuidos.

- "Cloud Strategy — Gregor Hohpe" (https://www.oreilly.com/library/view/cloud-strategy/9781492054590/) — Orientación para adoptar la nube como transformación técnica y organizativa.

- "Serverless Architectures on AWS — Peter Sbarski y Yan Cui" (https://www.manning.com/books/serverless-architectures-on-aws-second-edition) — Desarrollo de sistemas sin servidor mediante servicios administrados de AWS.
